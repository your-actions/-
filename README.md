# # ПЛАНЕТА ENERGY

Одностраничный веб-проект: визуальное исследование космоса и человеческого сознания, созданный под руководством Школы вожатых ENERGY.

Вёрстка по дизайн-макету (ПР № 3) и интерактивные компоненты на нативном JavaScript (ПР № 4).

## Демо

**Работающий сайт:** https://your-actions.github.io/

## О проекте

«Планета ENERGY» — это визуальное исследование космоса и человеческого сознания. Мы смотрим на звёзды, но на самом деле ищем отражение самих себя и тех, кого мы ведём за собой.

Проект объединяет ретро-футуризм и современный коллаж: планеты с кольцами, загадочные туманности и люди, чьи головы скрыты за галактиками, создают единое полотно. Каждое изображение в галерее — метафора: страх, мечта, поиск себя или «дом».

## Что реализовано

- Семантическая адаптивная вёрстка по макету (320 / 768 / 1440 px).
- Семь интерактивных компонентов на чистом JavaScript, без библиотек и сборки.
- Доступность: ARIA-атрибуты, управление с клавиатуры, заметный фокус.
- Валидация формы с сообщениями об ошибках и успешной отправке.

## Интерактивные компоненты

| № | Компонент | Поведение | Ключевые элементы |
|---|---|---|---|
| 1 | **Меню / бургер** | На десктопе — горизонтальная навигация. На ширине ≤ 760 px кнопка «Меню» раскрывает панель. Закрывается по повторному клику, по ссылке, по клику вне меню и по `Esc` с возвратом фокуса на кнопку. | `[data-js="menu"]`, `.nav.is-open`, `aria-expanded` |
| 2 | **Табы галереи** | Фильтрация карточек: «Все», «Планеты», «Люди». Состояние кнопок синхронизировано через `.is-active` и `aria-selected`. Клавиатура: `←`, `→`, `Home`, `End`. | `[data-js="tabs"]`, `data-tab`, `data-category`, `hidden` |
| 3 | **Аккордеон FAQ** | Одновременно открыт только один пункт. Повторный клик по открытому пункту закрывает его. | `[data-js="accordion"]`, `.accordion-item.is-open` |
| 4 | **Слайдер** | Переключение вперёд и назад по кругу, счётчик «1 / 3», управление стрелками клавиатуры. | `[data-js="slider"]`, `translateX`, `aria-live` |
| 5 | **Модальное окно** | Открывается через `dialog.showModal()`. Закрывается крестиком, кликом по затемнению или `Esc`. После закрытия фокус возвращается на кнопку открытия. | `[data-js="modal"]`, `#application-modal` |
| 6 | **Форма с валидацией** | `preventDefault()`, проверка имени через `trim()`, формата email по регулярному выражению, состояния чекбокса через `checked`. Вывод ошибок и сообщения об успехе. | `[data-js="form"]`, `aria-invalid`, `.form__error` |
| 7 | **Уведомление о cookie** | Появляется при первом визите, скрывается по кнопке «Принять». Факт принятия хранится в `localStorage`. | `[data-js="cookies"]` |
| 8 | **Диагностика** | Выводит в Console и в подвал количество найденных компонентов `[data-js]`. | `[data-js-status]` |

## Доступность

- Один `h1`, далее корректная иерархия `h2` / `h3`.
- Действия — `<button type="button">`, переходы — `<a href>`.
- У содержательных изображений осмысленный `alt`.
- У полей формы есть связанные `label` и `aria-describedby` на сообщения об ошибках.
- Фокус заметен (`:focus-visible`), все компоненты доступны с клавиатуры.
- Учтена настройка `prefers-reduced-motion` — анимации отключаются.

## Адаптивность

| Ширина | Что проверено |
|---|---|
| 320 px | одна колонка в галерее, меню-бургер, нет горизонтальной прокрутки |
| 768 px | промежуточное состояние, сетка и типографика не ломаются |
| 1440 px | контент ограничен контейнером 1120 px и центрирован |

## Запуск локально

```bash
git clone https://github.com/USERNAME/REPO.git
cd REPO
```

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Публикация на GitHub Pages

1. Запушьте проект в репозиторий на GitHub.
2. Откройте **Settings → Pages**.
3. В разделе *Build and deployment* выберите **Source: Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу `https://USERNAME.github.io/REPO/`.
